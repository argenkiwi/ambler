To eliminate coupling between nodes and walks, nodes specify state requirements through atomic Has* protocols rather than depending on a walk's concrete state. Ambler codifies a two-tier convention: atomic field protocols (Has<Field>) belong at the nodes package boundary (e.g. nodes/mod.rs, nodes/__init__.py, nodes/State.kt, nodes/state.ts), while composite state contracts (State) are declared inside the individual node file combining only what that node touches. Sibling nodes must never import state protocols from one another, which preserves node reusability across arbitrary walks. Walks in walks/ own the concrete state struct or dataclass and implement or satisfy all atomic protocols required by their constituent nodes.
