To sustain automated release cadence during agentic development, PRs enforce a semver increase in Cargo.toml against the target branch via a dedicated GitHub Action check, paired with a standing rule in AGENTS.md. Because AGENTS.md is compiled into amble and emitted verbatim into new projects, the instruction must remain project-neutral and follow semver without mentioning bespoke scripts. On merge to main, a release workflow compares Cargo.toml against the preceding commit (or github.event.before) and checks existing git tags, guaranteeing idempotency before invoking gh release create with contents: write permissions.
