utils/runner.rs decides where a delegated verb runs (nodes/delegate.rs does the running; walks/delegate.rs wires it). Local: cargo-ambler on PATH for Rust, cli.ts or node_modules/.bin/ambler plus bun for TypeScript, .venv/bin/ambler-cli plus uv for Python. Otherwise node/walk/util in TS/Python try bunx/uvx (global_runner on Target); Rust has no global runner. With nothing to run ambler does NOT fall back to its own scaffolding (it has none any more): it records the install diagnostic (cargo install --git ...ambler-rs cargo-ambler / bun install / uv sync), exits 2 and writes nothing. check never fetches via bunx/uvx, because it should run where the project own tools are, so for check a Global route is treated as Missing. The native CLI exit code is propagated (Error::Exit), so ATP codes 1 vs 2 reach the user. Specs must stick to the three allowed sections, so the protocol doc lives in docs/, not specs/.
