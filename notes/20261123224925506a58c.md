utils/runner.rs decides where a delegated verb runs. Local runner (.venv/bin/ambler-cli for Python, cli.ts for TS) requires the project to be set up AND uv/bun on PATH; otherwise node/walk/util try uvx/bunx (global_runner on Target), and if neither exists print the actionable diagnostic (uv sync / bun install) and fall back to amble built-in scaffolding. amble check uses delegate_local: it never fetches via uvx/bunx because running the target checks directly is more reliable than a network download, so it prints the diagnostic and runs Target::checks(). Python local detection is only .venv/bin/ambler-cli, not cli.py, since the entry point is installed by uv sync. Specs must stick to the three allowed sections, so the protocol doc lives in docs/, not specs/.
