amble generates ambler-rs (default) or ambler-ts projects. The target is resolved once in main.rs by scaffold::target::resolve: --target flag, then AMBLE_TARGET, then marker files (ambler.ts + package.json -> TS, Cargo.toml + src/engine.rs -> Rust; skipped for `new`, whose cwd is the parent), then Rust. It travels in State behind HasTarget, so per-verb strict args::parse never sees --target. Target is an enum, not a trait: with two targets, `match` at the few call sites (paths, checks, unfinished markers, formatter via Change.format: Option<Target>) is simpler, and planning nodes branch into plan_rust/plan_ts. Language-neutral pieces live in scaffold/{walk,lint,context}.rs; scaffold/rust/ uses syn, scaffold/ts/ uses oxc (pinned to 0.75 by rust-version 1.85). context.rs AGENTS/CLAUDE/SKILL are emitted to both targets, so they must stay target-neutral.
