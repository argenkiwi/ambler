Rather than forcing amble to parse foreign language ASTs in Rust (which blocked Kotlin and Mojo and created parser version pins), amble adopts a Federated Dispatcher model. Target::native_runner maps non-Rust targets to their native ATP-compliant runners (bun run ambler for TypeScript, uv run ambler-cli for Python), which self-contain their node/walk/util scaffolding, linters and test execution. Amble's walks (node, walk, util, check) transparently forward subcommands and arguments via process::run, preserving unified amble CLI ergonomics and pave orchestration while allowing language targets to evolve natively.
