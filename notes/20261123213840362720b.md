Rather than forcing amble to parse foreign language ASTs in Rust (which blocked Kotlin and Mojo and created parser version pins), amble is a Federated Dispatcher: the common entry point for what applies to every target (new, pave, help, target resolution) and a delegator for node, walk, util and check. Each target owns those verbs in its own native ATP CLI: cargo ambler (the cargo-ambler crate in ambler-rs/cli), bun run ambler, uv run ambler-cli. amble keeps no fallback implementation: the generators and linters were removed from amble. Known leftover: pave still reads node outcomes and registered state with per-language source parsers (scaffold/{rust,ts,py}/source.rs, register.rs), so syn, oxc and rustpython-parser stay as dependencies until pave gets an ATP verb for that.
