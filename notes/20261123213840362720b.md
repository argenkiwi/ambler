Rather than forcing ambler to parse foreign language ASTs in Rust (which blocked Kotlin and Mojo and created parser version pins), ambler is a Federated Dispatcher: the common entry point for what applies to every target (new, pave, help, target resolution) and a delegator for node, walk, util and check. Each target owns those verbs in its own native ATP CLI: cargo ambler (the cargo-ambler crate in ambler-rs/cli), bun run ambler, uv run ambler-cli. ambler keeps no fallback implementation and no source parsers: the generators, linters and the syn/oxc/rustpython readers were removed. pave used the parsers only to prefill prompts (node outcomes, existing state, node list); its prompts now point the agent at the spec, the state declarations and the node files, and the walk prompt runs ambler walk without --edge so the native verb leaves the wiring stubs to fill in.
