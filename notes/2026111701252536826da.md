The five ambler-* skills each carried code templates and had drifted (hard-coded ambler:: paths, DefaultUtils, an unquoted # truncating a description; azk forked them, PiDE dropped them). ambler keeps conventions only in guides compiled into the binary (src/guides, ambler help <topic>), next to the linter that enforces them. AGENTS.md holds a few always-loaded behavioural rules that point at guides, and a single skill routes trigger phrases to a verb and a guide. The skill earns its place over AGENTS.md alone because it can be installed globally, so an agent in an empty folder knows to run ambler new before any AGENTS.md exists. A test (guides::unknown_mentions) fails if either file names a verb or topic that does not exist. There is no init verb for adopting existing projects: ambler help agents prints the block to paste, since it happens once per project.
