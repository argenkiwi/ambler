amble new writes src/engine.rs with include_str! of amble's own src/engine.rs, and AGENTS.md, CLAUDE.md and the ambler skill with include_str! of the files at the repository root. The template core is therefore the core amble compiles and tests, and the agent instructions a new project gets are the ones amble itself is developed under. The cost is that those root files must stay project-neutral: nothing amble-specific can go in AGENTS.md. The engine lives in engine.rs (the PiDE layout) with a pub use from lib.rs, so crate::Node paths still read as in ambler-rs while the file can be emitted verbatim.
