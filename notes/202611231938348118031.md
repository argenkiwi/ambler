scaffold/py/node.rs and walk.rs emit text that already passes `ruff format --check`, ruff's I/E501 rules and strict pyright, because ambler only runs .venv/bin/ruff (check --fix --select I, then format) once `uv sync` has installed it. Lessons: (1) dataclass factories must name the parametrised type, field(default_factory=list[str]), since `list` is list[Unknown] under strict pyright; unknown types default to field(default_factory=T), so every walk State() is constructible. (2) Wrap with py::node::bracket, which mimics ruff: flat, else the arguments on one indented line without a trailing comma, else one per line with one; imports that don't fit go one name per line (isort style). Extreme names (60+ chars) still trip E501 in case patterns and strings that ruff itself can't wrap. (3) Unfinished markers are `not yet implemented` (node run, walk test Script) and `not yet wired` (walk arms), both raised as NotImplementedError, written with concat! so ambler's own lint doesn't flag itself. (4) A walk's Error is the one fallible node's Error, a tuple when several, absent when none (then no `import sys`). (5) Node and walk names that would shadow what the module defines (error, outcome, utils, state, run, main, id...) are rejected. (6) The pyproject sets pytest --import-mode=importlib so tests/nodes/test_x.py and tests/walks/test_x.py can coexist.
