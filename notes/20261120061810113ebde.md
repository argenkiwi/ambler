state_traits (scaffold/source.rs) derives each trait's fields from field_mut/set_field accessors, and, when a getter has neither, from the getter alone: the field owns what the getter lends (&[T] -> Vec<T>, &str -> String, Option<&str> -> Option<String>, &T -> T). Getter bodies lend Option fields with .as_deref(), or .as_ref() when the field is Option<T> and the getter returns Option<&T>. Each HasTrait also carries the paths of the use items in src/nodes/mod.rs that its field types mention (matched by identifier); generated node test modules and walk headers emit those uses, so MockState and State compile. `ambler node --state f:crate::x::T` shortens path types to their last segment (node::shorten) and inserts the use into mod.rs with register::add_use, in sorted position because mod.rs is not run through rustfmt. These fixed gaps found while generating ambler pave: a missing import for custom types, self.message instead of as_deref, and a todo!() for getter-only traits like HasArgs. ambler new also writes specs/.gitkeep so the specs folder exists from the start.
