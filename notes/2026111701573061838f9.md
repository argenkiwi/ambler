With no positional, amble new names the project after the current folder and plans its files at root-relative paths (scaffold::project takes a separate folder argument; empty means here). Only .git is tolerated, so git init followed by amble new works, while any other entry is rejected rather than risking overwriting files. A folder name that is not a valid package name is rejected with a hint to rename the folder, not sanitised, because a Cargo name silently different from the folder is surprising. The lint tests now build their example from project("app", "", ...) instead of stripping an app/ prefix. Existing wiring is unchanged: the branch lives entirely in the plan_project node, which gained current_folder and entries utils.
