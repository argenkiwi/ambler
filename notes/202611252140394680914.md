`Target::has_native_runner` for Rust now treats the project's CLI as present when `.cargo/config.toml` (or legacy `.cargo/config`) defines an `ambler` alias, either under `[alias]` or as a top-level `alias.ambler` dotted key; `xtask/Cargo.toml` and a global `cargo-ambler` still count. This exists because ambler-rs itself is the CLI and runs its own binary via the alias without an xtask crate (issue #6). Detection needs file contents, so `runner::route`, `has_native_runner` and `delegate::Utils` gained a `read` callback alongside `exists`. The parser (`has_cargo_alias`) is a deliberately small line scanner, not a TOML parser: it skips comment lines and ignores inline tables like `alias = { ambler = ... }`, and it only looks at the project folder, not Cargo's parent-directory or ~/.cargo config hierarchy.
