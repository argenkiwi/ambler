The TS node/walk generators emit text exactly as Biome 2.6 formats it (80 cols, curried-arrow factory, union broken one member a line, edges record broken in two levels) because the write node only runs node_modules/.bin/biome when bun install has happened; the golden test reproduces ambler-ts's walks/counter.ts byte for byte. Unfinished TS code is marked by `not yet implemented` (node stubs, walk test script()) and `unwired(` (a local never-returning function the walk defines when an edge or an initial-state value is unknown); Target::unfinished() lists them for both the todo lint rule and pave's task selection. A node whose only edge is onDone is terminal (wired to null) unless --edge names it. --fallible is rejected for TS: nodes throw or route failures through an edge. Empty TS projects use `bun test --pass-with-no-tests` and .gitkeep files, since bun test exits 1 with no test files.
