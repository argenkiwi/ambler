ambler-rs/cli is the native ATP CLI for Rust. It was ported from amble Rust generators and walks, so its node/walk/util output is byte-identical to what amble generated (checked by diffing src/ and specs/ of two scratch projects). Cargo runs cargo-ambler ambler <verb> for cargo ambler <verb>, so main.rs drops a leading ambler argument. Exit codes: 1 for check failures and for something that already exists (the walk State::finish tests the message for already), 2 for bad arguments or not being in a project. Lint tests build the example project from templates/ via the test-only fixture() in scaffold/rust/project.rs, because new lives in amble.
