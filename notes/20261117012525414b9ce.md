ambler walk parses each node file with syn (proc-macro2 span-locations, to slice exact source text for signatures and types) to get its Outcome variants, Error, Has* bounds and Utils methods, then generates State, Id, the generic struct and the exhaustive step. Edges come from --edge node.Outcome=node|halt; any outcome without one becomes a todo!("wire ...") arm, so the file compiles and ambler check reports the arm under the todo rule until it is wired. Generated code is not hand-indented: the write node runs rustfmt on files flagged for it, and the golden test compares against the reference counter walk ignoring whitespace and comments. Gotchas: a Utils method returning impl Future needs an async { todo!() } stub because ! is not a Future; the wiring test must import the types the Utils signatures mention, taken from the node file's own use items; a walk named new trips clippy::self_named_constructors, so ambler's own new walk calls its struct NewProject. The lint rule for todo scans for the literal macro call in nodes, walks and utils, so tests there must not contain that literal.
